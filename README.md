# FirstKotlinRepo

My first Kotlin project, built while learning the language from scratch, just me working through bugs and concepts by hand reading the documentation.

## Projects

### Email & Password Manager (`EmailManage.kt`)
A console based account manager with a menu system:
- Add an account (with email format and password length validation)
- Remove an account
- Display all saved accounts

No file I/O yet — data is only stored for the run time

**What this project taught me:**
- Using a `Map` correctly for real storage and misusing it just to pass values between functions lol {fixed by switching to `Pair`}
- Learned Collections
- Bit of debugging
